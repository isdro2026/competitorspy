## 🎯 What is CompetitorSpy?

CompetitorSpy automatically:
1. **Scrapes competitor websites** → Extracts keywords, content structure
2. **Analyzes top competitors** → Identifies winning strategies
3. **Generates marketing content** → Blog posts, social media, ads, landing pages
4. **Automates posting** → Schedule content across social platforms (future)

**Perfect for:**
- Solopreneurs
- Digital agencies
- E-commerce brands

## 🚀 Get Started (45 Minutes)

### Step 1: Gather API Keys (15 min)
Get free keys from:
- [ ] **Supabase** (Database) → supabase.com
- [ ] **Firecrawl** (Scraping) → firecrawl.dev
- [ ] **Claude** (Content Gen) → console.anthropic.com
- [ ] **Perplexity** (optional) → perplexity.ai

### Step 2: Setup Database (5 min)
1. Create Supabase project
2. Go to SQL Editor
3. Copy `database.sql` and run
4. Done!

### Step 3: Setup Local (10 min)
```bash
# Navigate to project
cd competitorspy

# Install packages
npm install

# Create .env.local
cp .env.example .env.local

# Add your API keys to .env.local
```

### Step 4: Run Locally (5 min)
```bash
npm run dev
# Visit: http://localhost:3000
```

### Step 5: Deploy to Vercel (10 min)
```bash
npm install -g vercel
vercel
# Add env variables in dashboard
```

## 🎮 How to Use

### Add a Competitor
1. Enter: Name, Website, Industry
2. Click "Add Competitor"
3. Competitor saved to database ✓

### Scrape Website
1. Click "Scrape" on competitor
2. Firecrawl crawls the site
3. Keywords extracted automatically
4. Data stored in PostgreSQL

### Generate Content
1. Select competitor
2. Choose content type (blog, social, ads, landing page)
3. Choose platform (Instagram, Facebook, LinkedIn, etc.)
4. Click "Generate Content"
5. Claude creates content automatically
